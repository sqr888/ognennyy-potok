# Глава: Основные понятия платформы 1С:Предприятие

## Вопрос: Что такое конфигурация в системе 1С:Предприятие?

- [ ] Набор настроек операционной системы
- [x] Совокупность объектов метаданных, определяющих структуру и поведение прикладного решения
- [ ] База данных с пользовательскими данными
- [ ] Набор внешних отчётов и обработок

**Описание:** Конфигурация — это описание прикладного решения, разработанное в конфигураторе. Она содержит объекты метаданных (справочники, документы, регистры и т.д.), формы, модули и другие элементы.

## Вопрос: Сколько режимов запуска существует в системе 1С:Предприятие 8?

- [ ] Один: режим 1С:Предприятие
- [ ] Два: конфигуратор и режим 1С:Предприятие
- [x] Три: конфигуратор, режим 1С:Предприятие и режим отладки
- [ ] Четыре режима

**Описание:** Система запускается в трёх режимах: «Конфигуратор» (разработка и администрирование), «1С:Предприятие» (работа пользователя) и «Отладка» (режим отладки прикладных решений).

## Вопрос: Что понимается под термином «объекты метаданных»?

- [x] Структурные единицы конфигурации, описывающие данные и логику работы системы
- [ ] Записи в информационной базе
- [ ] Файлы на диске, хранящие данные пользователей
- [ ] Внешние компоненты системы

**Описание:** Объекты метаданных — это структурные единицы конфигурации 1С: справочники, документы, регистры сведений, регистры накоплений, отчёты, обработки и т.д. Они описывают структуру хранения и обработки данных.
